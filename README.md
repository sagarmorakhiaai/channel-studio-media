# channel-studio-media

Finished videos from [channel-studio](https://github.com/sagarmorakhiaai/channel-studio), kept out of the code repository.

- The cloud session renders a video and pushes it here: `<channel>/<video id>-<language>.mp4`.
- Sagar watches it. Approval is recorded in the ledger in `channel-studio`, never here.
- The Mac pulls this repository and publishes **only** videos the ledger marks as approved.

A file being here does not mean it is approved. Nothing in this repository is published automatically.
